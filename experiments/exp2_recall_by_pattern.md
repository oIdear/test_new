## 4. 旧系统失败原因分析

| Pattern | 旧系统命中率 | 失败原因 |
|---|---|---|
| a1（RPKI验证） | 16.7% | 旧查询词混入大量 AS 路径字符串和数值分数，语义被稀释；旧知识库无 rfc6811/rfc8893，RPKI 内容覆盖不足；检索结果全部偏向 2402论文 |
| a3（保留ASN） | 0% | 同上；"reserved ASN"相关内容在旧知识库中极少；向量检索无法区分数值噪声 |
| a4（同源组织） | 50% | 旧查询词含 2000 字符数值噪声，语义信号弱，随机命中概率低 |
| a2（valley-free） | 100% | valley-free 关键词语义特征明显，即使旧查询词含噪声，向量模型仍能找到相关文档 |

## 5. 未命中案例分析

**gid=24（a3 类型，新旧系统均未命中）**

该告警主导 pattern 为 a3（保留ASN路径），期望关键词为 `reserved`、`AS_PATH`、`AS number`、`autonomous system`。检索结果全部来自 2402论文，其中包含 "AS number" 但未明确讨论保留 ASN 的规范（应参考 RFC 7300 / RFC 6793 等，当前知识库不含这些文档）。

**改进建议：** 补充 RFC 7300（保留ASN）到知识库。

---

## 6. 关键发现

- 新系统相比旧系统召回率提升 **+50 个百分点**（45% → 95%）
- **a1 类型提升最大**（16.7% → 100%）：由两个因素共同驱动——新增 rfc6811/rfc8893 覆盖 RPKI 内容，以及语义查询词精准匹配 RPKI 相关文档
- **a3 类型从 0% 提升到 80%**：主要依赖查询词语义去噪，即使知识库覆盖有限也能命中 2402论文中的相关描述
- **a2 类型两者持平（100%）**：valley-free 关键词语义特征强，旧系统即可正确检索
- 旧系统的"万能旧查询"导致检索结果 **95% 集中在 2402论文**（BEAM模型论文），完全忽略 RFC 文档；新系统多样性翻倍（1.05 → 2.10）
